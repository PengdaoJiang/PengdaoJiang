# Agent and Research Systems

Research workflows, agent decision experiments and reproducible computation for long-running work.

## Main projects

| Project | Central problem | Code and architecture |
| --- | --- | --- |
| [Research review workbench](https://github.com/PengdaoJiang/document-review-workbench) | Turn claims into research obligations; preserve conclusions and improve workflows from actual rework | [Research cycle](https://github.com/PengdaoJiang/document-review-workbench/blob/main/docs/research-workflow.md) |
| [Agent decision experiments](https://github.com/PengdaoJiang/traceable-translation-pipeline) | Model information, action and stopping; compare assessment designs and preserve unresolved objections | [Decision kernels and runnable case](https://github.com/PengdaoJiang/traceable-translation-pipeline/blob/main/docs/decision-experiments.md) |
| [Reproducible experiment runtime](https://github.com/PengdaoJiang/point-in-time-research) | Coordinate research judgment, model-free computation and event handoff | [Research orchestration](https://github.com/PengdaoJiang/point-in-time-research/blob/main/docs/research-orchestration.md) |
| [Agent execution and evaluation](https://github.com/PengdaoJiang/agent-eval-evidence-kit) | Carry current assignments and conditions through native execution and independent evaluation | [Research work packages](https://github.com/PengdaoJiang/agent-eval-evidence-kit/blob/main/docs/research-work-packages.md) |

The repositories contain extracted working implementations with independent entry points. Their guides identify deployment dependencies, synthetic examples and the scope of historical validation.
